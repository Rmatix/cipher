# Contribuir a Cipher

Gracias por querer ayudar a Cipher. El proyecto esta en una etapa temprana, asi que las contribuciones mas utiles son bugs reproducibles, mejoras pequenas y pruebas en equipos Windows reales.

## Como empezar

```bash
pnpm install
pnpm dev
```

Antes de abrir un pull request:

```bash
pnpm lint
pnpm build
```

## Buenas primeras tareas

- Reproducir y documentar bugs con pasos claros.
- Mejorar accesibilidad, estados vacios y responsive del renderer.
- Agregar pruebas manuales para IA, Git, terminal y explorador.
- Mejorar empaquetado Windows y documentar requisitos C++ de `node-pty`.
- Traducir textos que todavia no tengan acentos o consistencia.

## Estilo

- Mantener cambios pequenos y enfocados.
- No subir API keys, tokens, capturas privadas ni `node_modules`.
- Explicar en el PR que se cambio, como se probo y que riesgos quedan.

## Donativos

Los donativos deberian usarse para firma de builds, pruebas en mas equipos, diseno, hosting de documentacion y tiempo de desarrollo.
